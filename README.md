# 小学英语单词闯关

一个给小学生背单词用的单页小游戏：把自己的单词表导进去，五种题型轮着练，答对有得分和连击奖励，答错扣分扣血，血用完就闯关失败。

**零依赖**：整个游戏就是一个 `index.html`，没有 CDN、没有字体文件、没有图片、没有音频，双击即用；发音用浏览器自带的语音合成（`speechSynthesis`）。

**在线玩**：<https://wuwuii.github.io/kids-english-quiz/>

![首页](screenshots/home.png)

## 快速开始

1. 下载 `index.html`，双击用 Chrome / Edge 打开
2. 在「题库」里粘贴、拖入或选择自己的单词表
3. 点开始闯关

单词表一行一条，两种写法都认：

```text
bull, 公牛
公牛 — bull
```

带逗号的句子也能正确切分（`Yes, they are., 是的，它们是。`）。导入时会自动去重、跳过注释和标题行，并告诉你识别了几条、跳过了几行。

## 五种题型

| 题型 | 玩法 | 得分 |
|---|---|---|
| 连线配对 | 左边英文、右边中文，各 4 项，点选配对 | 配对正确 +8，配错 −3 |
| 中译英 | 四选一 | +10（连对 3 题额外 +5） |
| 英译中 | 四选一 | 同上 |
| 听音选词 | 自动播报英文，点出听到的词 | 同上 |
| 补全单词 | 缺 1~3 个字母，从字母块点选填入 | +12 |

四选一的干扰项按「单词 / 短语 / 句子」同形状挑选，不会在单词题里蹦出一整个句子。

## 关卡递进

- 第 1 关：连线 + 选择
- 第 2 关：加听音
- 第 3 关：加拼写
- 第 4~5 关：全题型混合

每关答错会扣分并扣 1 点生命，连线/拼写错一次也扣；生命归零 → 本关作废，可以「重来本关」或回首页。

## 可调项

- 语速 0.6 ~ 1.2
- 每关题数 6 / 8 / 10
- 初始生命 3 / 5

题库和设置存在浏览器 localStorage，下次打开还在。

## 兼容性

- Chrome / Edge / Safari 现代版本
- 手机竖屏适配（375px 无横向滚动）

## 已知限制

- 发音依赖系统自带英文音色。Windows 上的 Chrome / Edge 一般有；没有音色的环境听音题会退化成看选项，题仍可答。
- 没有账号系统，数据只存在本机浏览器。
